# Relatório de engenharia

Use `nablamath.documents.profiles.build_profile('engineering_report', ...)` com
`Requirements`, `Model`, `Verification`, `Results` e `Operating limits`.
A seção Verification deve citar evidências; dados sintéticos precisam ser marcados.
O perfil usa o mesmo AST e os mesmos exportadores HTML/LaTeX/Typst do artigo.
O laboratório `tools/reproduce_maturity.py` compila o exemplo e confere seu bundle.
