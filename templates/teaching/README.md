# Material didático

Use `nablamath.documents.profiles.build_profile('teaching', ...)` com
`Learning objectives`, `Assumptions`, `Worked examples`, `Exercises` e `Solutions`.
Os exemplos resolvidos devem apontar para evidências verificáveis. As soluções
ficam em seção própria; nenhuma avaliação de estudante é executada pelo perfil.
O laboratório `tools/reproduce_maturity.py` compila o exemplo e confere seu bundle.
